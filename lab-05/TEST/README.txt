# THBMTTNC - Bài Kiểm Tra Kết Thúc Môn Học

## Sinh viên: Ngô Thái Nguyên - MSSV: 2280602114

### Cách chạy:

1. Cài đặt thư viện Flask:
   pip install flask

2. Chạy ứng dụng:
   cd THBMTTNC_Final_Project
   python test_app.py

3. Truy cập trình duyệt:
   http://localhost:5050
